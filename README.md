# Coffee Shop Business Analysis

This project analyzes a Coffee Shop dataset using Python.

## Project Steps

- Data Cleaning
- Data Preparation
- Exploratory Data Analysis
- Univariate Analysis
- Data Visualization
  
## 📊Business Insights
### 1. Product Analysis

![Product Analysis](https://github.com/Gunelhasan/Coffee-Shop-Business-Analysis-using-Python/blob/main/product.png)

Müşahidə:
Ən çox sifariş edilən məhsul Latte-dir.

Potensial biznes qərarı:
Coffee Shop bu məhsulun stokunun kifayət qədər olmasını təmin edə və onunla əlaqəli bundle və ya kampaniyalar hazırlaya bilər.

### 2. Payment Method Analysis

Müşahidə:
Müştərilərin böyük hissəsi Card ödəniş üsulundan istifadə edir.

Potensial biznes qərarı:
Coffee Shop həmin ödəniş infrastrukturunun fasiləsiz işləməsini prioritet hesab edə bilər.

### 3. Order Size Analysis

Müşahidə:
Sifarişlərin əksəriyyəti Small kateqoriyasındadır.

Potensial biznes qərarı:
Coffee Shop bundle kampaniyaları vasitəsilə müştəriləri daha çox məhsul almağa təşviq edə bilər.

### 4. Revenue Analysis

Müşahidə:
Sifarişlərin böyük hissəsi Low Revenue kateqoriyasına daxildir.

Potensial biznes qərarı:
Daha yüksək gəlirli sifarişlərin sayını artırmaq üçün upselling və xüsusi təkliflər tətbiq edilə bilər.

### 5. Order Quantity Analysis

Müşahidə:
Müştərilər ən çox 1–4 məhsul sifariş edirlər.

İzah:
Quantity paylanması sifarişlərin əsasən müəyyən bir miqdar ətrafında toplandığını göstərir.

Potensial biznes qərarı:
2 və ya 3 məhsullu paketlər yaradılaraq orta sifariş miqdarı artırıla bilər.

### 6. Order Revenue Analysis

Müşahidə:
Sifariş məbləğlərinin böyük hissəsi 5–8 AZN aralığında yerləşir.

İzah:
Bu aralıq Coffee Shop üçün tipik sifariş məbləğini göstərir.

Potensial biznes qərarı:
Kampaniyalar və məhsul paketləri bu tipik sifariş məbləğindən bir qədər yuxarı səviyyədə qurularaq Average Order Value artırıla bilər.
